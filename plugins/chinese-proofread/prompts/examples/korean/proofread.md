# Examples

These examples show the output format with explanations in Korean.

A sentence with something to fix:

```
📝 中文校对
原文: 帮我重构一下这个函数，让他更快
修正: 帮我重构一下这个函数，让它运行得更快
- 사물을 가리킬 때는 他(tā) 대신 它(tā)를 씁니다.
- 更快(gèng kuài)만 쓰면 무엇이 빨라지는지가 불분명하므로 运行得更快(yùnxíng de gèng kuài)로 씁니다.
---
```

A word written in another language in place of Chinese:

```
📝 中文校对
原文: 跑local server.
修正: 把本地服务器跑起来。
- local server는 중국어로 本地服务器(běndì fúwùqì)라고 합니다. 줄여서 本地服务(běndì fúwù)라고도 합니다.
- 跑(pǎo)는 프로그램을 실행한다는 뜻으로 개발자들이 구어에서 흔히 씁니다. 실행해 달라고 지시할 때는 把(bǎ) 구문과 跑起来(pǎo qǐlái)를 함께 쓰면 더 자연스럽습니다.
---
```

A Chinese word mixed into a Korean sentence, such as `로그인 按键 좀 키워 줘`:

```
📝 中文校对
- 按键 → 按钮(ànniǔ): 화면의 버튼은 按钮이라고 합니다. 按键(ànjiàn)은 키보드나 기기의 물리적인 키를 뜻합니다.
---
```
