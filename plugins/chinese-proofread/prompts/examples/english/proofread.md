# Examples

These examples show the output format with explanations in English.

A sentence with something to fix:

```
📝 中文校对
原文: 帮我重构一下这个函数，让他更快
修正: 帮我重构一下这个函数，让它运行得更快
- Use 它(tā) instead of 他(tā) to refer to a thing.
- 更快(gèng kuài) alone does not say what gets faster, so write 运行得更快(yùnxíng de gèng kuài).
---
```

A word written in another language in place of Chinese:

```
📝 中文校对
原文: 跑local server.
修正: 把本地服务器跑起来。
- local server is 本地服务器(běndì fúwùqì) in Chinese. It is also shortened to 本地服务(běndì fúwù).
- Developers often say 跑(pǎo) for running a program in speech. When asking someone to run it, the 把(bǎ) construction with 跑起来(pǎo qǐlái) sounds more natural.
---
```

A Chinese word mixed into an English sentence, such as `make the login 按键 bigger`:

```
📝 中文校对
- 按键 → 按钮(ànniǔ): A button on a screen is 按钮. 按键(ànjiàn) means a physical key on a keyboard or device.
---
```
