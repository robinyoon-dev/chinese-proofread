For example, if you fixed `让他更快` to `让它运行得更快`, write the explanations in English like this.

```
- 他(tā) refers to a person; a thing such as a function is 它(tā). They sound the same and only the character differs.
- 更快(gèng kuài) alone does not say what gets faster, so use the complement of degree, "verb + 得(de) + adjective": 运行得更快(yùnxíng de gèng kuài). Example: 跑得很快(pǎo de hěn kuài).
```
