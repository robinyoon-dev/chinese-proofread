# 중국어 입력 교정

사용자는 중국어를 연습하는 중이며, 업무 지시를 중국어로 내리면서 그 문장도 함께 교정받고 싶어 합니다. 이 스킬은 요청을 처리하기 전에 사용자의 중국어 문장을 먼저 교정하고, 그다음에 원래 요청을 수행하도록 순서를 정합니다.

## 순서

1. 사용자가 직접 쓴 중국어 문장을 찾습니다.
2. 각 문장이 문법적으로 맞는지, 그리고 원어민이 실제로 쓰는 표현인지 판단합니다.
3. 아래 형식에 따라 교정 결과를 응답의 맨 앞에 출력합니다.
4. 교정된 문장이 뜻하는 내용을 기준으로 원래 요청을 수행합니다.

## 교정 대상

- 사용자가 직접 쓴 문장만 교정합니다.
- 사용자가 붙여 넣은 코드, 로그, 에러 메시지, 인용문, 파일 경로, 식별자는 교정하지 않습니다.
- 사용자가 다른 사람의 중국어 문장을 붙여 넣고 그 문장을 봐 달라고 요청했다면, 그 문장은 교정 대상에 포함합니다.
- 교정할 대상이 하나도 없다면 교정 블록을 출력하지 않고 바로 요청을 수행합니다.

## 판단 기준

- 문법 오류뿐 아니라, 문법적으로는 맞지만 원어민이 쓰지 않는 어색한 표현도 고칩니다.
- 사용자의 어조는 유지합니다. 구어체로 쓴 문장을 문어체로 바꾸지 않고, 짧은 지시문을 길게 늘이지 않습니다.
- 사용자가 쓴 간체자나 번체자를 그대로 유지합니다.
- 개발 용어는 중국어권 개발자가 실제로 쓰는 표현을 기준으로 판단합니다. 예를 들어 `bug`, `commit`처럼 영어를 섞어 쓰는 것이 자연스러운 경우에는 그대로 둡니다.
- 사소한 문장부호 차이만 있다면 교정하지 않고 자연스럽다고 판단합니다.

## 중국어 대신 쓴 단어

사용자는 중국어로 어떻게 말하는지 모르는 단어를 영어나 한국어로 대신 쓰기도 합니다. 예를 들어 `跑local server.`에서 `local server`는 사용자가 `本地服务器`라는 말을 몰라서 영어로 쓴 단어입니다.

- 이런 단어는 중국어권 개발자가 실제로 쓰는 중국어 표현으로 바꾸어 `修正` 문장에 반영하고, 설명에서 그 단어를 중국어로 어떻게 말하는지 알려 줍니다.
- 설명은 `local server는 중국어로 本地服务器(běndì fúwùqì)라고 합니다.`처럼 원래 단어, 중국어 표현, 병음을 한 줄에 함께 씁니다. 그 단어와 어울려 쓰는 동사나 양사가 따로 있다면 같은 줄에 덧붙입니다.
- `bug`, `commit`, `PR`처럼 중국어권 개발자도 영어를 그대로 쓰는 단어는 바꾸지 않고, 설명도 덧붙이지 않습니다. 중국어 표현과 영어 표현을 모두 흔히 쓴다면 영어를 그대로 두되, 설명에 중국어 표현을 한 줄로 알려 줍니다.
- 코드, 명령어, 파일 경로, 식별자처럼 원래 영어로 써야 하는 부분은 대신 쓴 단어로 보지 않습니다.
- 문장 전체가 짧아도 교정 블록을 생략하지 않습니다. `跑local server.`처럼 한자가 한 글자뿐인 문장도 교정 대상입니다.

## 출력 형식

설명에 쓰는 언어는 훅이 지정한 언어를 따릅니다. 훅이 언어를 지정하지 않았다면 한국어로 설명합니다.

교정할 부분이 있는 경우에는 다음 형식으로 출력합니다.

```
📝 中文校对
原文: 帮我重构一下这个函数，让他更快
修正: 帮我重构一下这个函数，让它运行得更快
설명:
- 사물을 가리킬 때는 他(tā) 대신 它(tā)를 씁니다.
- 更快(gèng kuài)만 쓰면 무엇이 빨라지는지가 불분명하므로 运行得更快(yùnxíng de gèng kuài)로 씁니다.
---
```

중국어 대신 다른 언어로 쓴 단어가 있는 경우에는 다음과 같이 출력합니다.

```
📝 中文校对
原文: 跑local server.
修正: 把本地服务器跑起来。
설명:
- local server는 중국어로 本地服务器(běndì fúwùqì)라고 합니다. 줄여서 本地服务(běndì fúwù)라고도 합니다.
- 跑(pǎo)는 프로그램을 실행한다는 뜻으로 개발자들이 구어에서 흔히 씁니다. 실행해 달라고 지시할 때는 把(bǎ) 구문과 跑起来(pǎo qǐlái)를 함께 쓰면 더 자연스럽습니다.
---
```

어색한 부분이 없는 경우에는 다음 한 줄만 출력합니다.

```
📝 中文校对: ✅ 자연스럽습니다.
```

문장이 여러 개라면 고친 문장만 `原文`과 `修正`으로 짝지어 보여 줍니다. 설명은 고친 이유마다 한 줄로 짧게 씁니다.

설명에서 중국어 단어나 구절을 언급할 때는 바로 뒤에 괄호로 한어병음을 덧붙입니다.

- 병음은 숫자(`ta1`)가 아니라 성조 부호(`tā`)로 표기합니다. 경성은 부호 없이 씁니다(`de`).
- 병음은 단어 단위로 띄어 씁니다. 예를 들어 `运行得更快`는 `yùnxíng de gèng kuài`로 씁니다.
- 같은 설명 줄에서 같은 단어를 다시 언급할 때는 병음을 한 번만 붙입니다.
- `原文`과 `修正` 줄에는 병음을 붙이지 않습니다. 문장 전체에 병음을 붙이면 원문과 수정문을 비교하기 어려워지기 때문입니다.

## 요청 수행

- 교정 블록을 출력한 뒤에는 곧바로 원래 요청을 수행합니다. 교정만 하고 멈추지 않습니다.
- 원문의 오류 때문에 요청이 두 가지 이상으로 해석되고, 해석에 따라 수행할 작업이 달라진다면 작업을 시작하기 전에 어떤 뜻이었는지 사용자에게 확인합니다.
- 요청에 대한 답변은 사용자가 따로 지정하지 않았다면 설명에 쓴 언어로 작성합니다.
