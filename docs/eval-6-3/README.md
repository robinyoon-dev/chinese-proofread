# 교정 품질 평가 중간 기록

이 폴더에는 교정 품질 평가(6-3 단계)를 진행하면서 남긴 중간 기록을 모았습니다. 각 문서는 기록한 시점의 구조와 판단을 기준으로 작성했으므로, 지금 구조와 다른 내용이 있을 수 있습니다. 최종 수치는 [평가 결과](../eval-results.md)에 있고, 지금 구조를 요약한 글은 [설계와 평가](../design-and-evaluation.md)에 있습니다.

아래 표는 작업을 진행한 순서대로 문서를 나열합니다. 1단계 기준 점수는 점검 실행과 출력 위치 확인 사이에 측정했으며, [평가 결과](../eval-results.md)에 기록했습니다.

| 순서 | 문서 | 내용 |
| --- | --- | --- |
| 1 | [시범 실행](pilot.md) | 평가 세트를 만들기 전에 `claude plugin eval`의 동작을 직접 확인한 결과를 기록합니다. |
| 2 | [1회 점검 실행](dev-run.md) | 기준 점수를 측정하기 전에 케이스와 채점자를 점검한 결과를 기록합니다. |
| 3 | [출력 위치 수정의 효과 확인](output-position.md) | `SKILL.md`에서 교정 결과의 출력 위치를 바꾼 뒤 Sonnet으로 효과를 확인한 결과를 기록합니다. |
| 4 | [남은 `SKILL.md` 개선 사항](skill-review.md) | 3번 실행의 응답을 다시 읽고 더 고쳐야 할 부분을 정리합니다. |
| 5 | [수정 후 재평가](rerun.md) | `SKILL.md`를 고친 뒤 Sonnet과 Opus를 다시 실행해 기준 점수와 비교합니다. |
