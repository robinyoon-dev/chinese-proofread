# 설정과 세부 동작

이 문서는 환경 변수 전체와 답변 언어 규칙, 세부 동작, 한계를 설명합니다. 설치 방법과 기본 사용법은 [README](../README.md)에서 설명합니다.

## 환경 변수

환경 변수로 동작을 조정할 수 있습니다. 값은 `~/.claude/settings.json`의 `env`에 추가하며, 추가하거나 바꾼 뒤에는 Claude Code를 다시 시작해야 반영됩니다. 작성 예시는 [README의 설정](../README.md#설정)에 있습니다.

| 환경 변수 | 기본값 | 설명 |
|---|---|---|
| `CHINESE_PROOFREAD_ENABLED` | (없음) | `0`으로 설정하면 교정 기능을 끕니다. 사용 방법은 [특정 프로젝트에서 항상 끄기](#특정-프로젝트에서-항상-끄기)에서 설명합니다. |
| `CHINESE_PROOFREAD_LANG` | `Korean` | 교정 블록의 설명과 `✅` 줄에 사용할 언어입니다. |
| `CHINESE_PROOFREAD_CHAT_LANG` | (없음) | 교정 블록 밖에서 Claude가 사용자에게 하는 말에 사용할 언어입니다. 지정하지 않으면 `CHINESE_PROOFREAD_LANG`과 같은 언어를 쓰고, `prompt`로 설정하면 요청을 쓴 언어를 씁니다. 자세한 동작은 [답변 언어](#답변-언어)에서 설명합니다. |
| `CHINESE_PROOFREAD_LEVEL` | `intermediate` | 학습 수준입니다. 자세한 동작은 [학습 수준](#학습-수준)에서 설명합니다. |
| `CHINESE_PROOFREAD_MIN_HANZI` | `4` | 중국어로 판별하는 데 필요한 최소 한자 수입니다. |
| `CHINESE_PROOFREAD_MIN_HANZI_MIXED` | `1` | 영문자나 한글이 섞인 입력에 적용하는 최소 한자 수입니다. `CHINESE_PROOFREAD_MIN_HANZI`보다 크게 설정하면 `CHINESE_PROOFREAD_MIN_HANZI` 값을 씁니다. |
| `CHINESE_PROOFREAD_HANZI_RATIO` | `0` | 한자와 한글을 합한 글자 수에서 한자가 차지해야 하는 최소 비율입니다. `0.5`로 설정하면 한자가 적은 한국어 문장을 교정 대상에서 뺍니다. |
| `CHINESE_PROOFREAD_HISTORY` | (없음) | `0`으로 설정하면 교정 이력을 기록하지 않습니다. 자세한 내용은 [교정 이력](#교정-이력)에서 설명합니다. |
| `NO_COLOR` | (없음) | 값이 있으면 교정 블록에 색을 입히지 않습니다. 플러그인 전용이 아니라 여러 프로그램이 함께 따르는 환경 변수입니다. |

숫자를 받는 설정에 숫자가 아닌 값을 넣으면 그 설정은 기본값으로 동작합니다.

`MIN_HANZI`, `MIN_HANZI_MIXED`, `HANZI_RATIO`가 판별에 어떻게 쓰이는지는 [중국어 판별 기준](development.md#중국어-판별-기준)에서 설명합니다.

## 답변 언어

Claude가 쓰는 텍스트는 교정 블록, 대화 응답, 작업 결과물의 세 가지로 나뉘며, 각각 다른 기준으로 언어를 정합니다.

| 구분 | 포함하는 내용 | 언어를 정하는 기준 |
|---|---|---|
| 교정 블록 | 교정한 이유의 설명, 단어 교정 줄, `✅` 줄 | `CHINESE_PROOFREAD_LANG` |
| 대화 응답 | 교정 블록 밖에서 사용자에게 하는 말 (작업 중의 진행 상황, 되묻는 질문, 결과 요약) | `CHINESE_PROOFREAD_CHAT_LANG` |
| 작업 결과물 | 코드, 코드 주석, 커밋 메시지, 작성을 요청한 파일의 내용 | 요청 내용과 저장소의 관례 |

- 기본값에서는 중국어로 요청해도 대화 응답을 한국어로 씁니다. 작업 결과에는 무엇을 지웠는지, 테스트를 실행했는지처럼 잘못 읽으면 곤란한 내용이 들어가므로, 중국어로 답변을 받으려면 직접 설정하도록 했습니다.
- Claude가 그래도 최종 답변을 중국어로 쓰면, 플러그인이 지정한 언어로 한 번 다시 쓰게 합니다. 처음 쓴 중국어 답변은 화면에 남고, 그 아래에 `Stop hook error:`로 시작하는 영어 안내문과 다시 쓴 답변이 이어서 나옵니다. `error`는 Claude Code가 붙이는 문구이며 실제 오류가 아닙니다.
- 요청에 `中文`이나 `汉语`가 있으면 Claude가 중국어로 답해도 다시 쓰지 않습니다.
- 프롬프트에서 답변 언어를 직접 지정하면 설정보다 그 지정을 따릅니다.
- 인용하거나 붙여 넣은 중국어만 있는 요청에서는 Claude가 사용자가 직접 쓴 말의 언어로 답합니다. 영어 문장에 중국어 단어를 섞은 요청도 영어로 답할 수 있습니다.
- 작업 결과물에는 이 설정을 적용하지 않습니다. 예를 들어 `用中文写注释`라고 요청하면, 대화 응답이 한국어여도 주석은 중국어로 씁니다.

중국어로 요청했을 때 중국어로 답변을 받으려면 `~/.claude/settings.json`에 다음 내용을 추가합니다.

```json
{
  "env": {
    "CHINESE_PROOFREAD_CHAT_LANG": "prompt"
  }
}
```

## 학습 수준

`CHINESE_PROOFREAD_LEVEL`은 무엇을 고칠지와 설명을 얼마나 자세히 쓸지를 정합니다.

| 값 | 고치는 범위 | 설명 |
|---|---|---|
| `beginner` | `intermediate`와 같습니다. | 고친 이유마다 한 줄을 쓰되, 문법 항목의 이름과 짧은 예를 덧붙입니다. |
| `intermediate` (기본값) | 틀렸거나 원어민이 어색하게 느끼는 표현만 고칩니다. | 고친 이유마다 한 줄로 짧게 씁니다. |
| `advanced` | `intermediate`의 범위에 더해, 문법이 맞더라도 한 문장 안에서 어조나 격식이 어긋나는 부분을 고칩니다. | 고친 이유마다 한 줄로 짧게 쓰고, 고치지 않은 부분에 관한 줄은 쓰지 않습니다. |

- 병음은 모든 수준에서 설명에 나오는 단어에 붙입니다.
- `advanced`에서도 문장 전체의 어조는 유지합니다. 예를 들어 구어체로 쓴 문장은 문어체로 바꾸지 않고, `麻烦您…搞一下`처럼 한 문장 안에서 어조가 어긋나는 부분만 문장의 나머지에 맞춥니다. 더 자연스럽거나 간결한 다른 표현이 있다는 이유만으로는 고치지 않습니다.
- 그 밖의 값을 넣으면 `intermediate`로 동작합니다. HSK 급수는 받지 않습니다.

예를 들어 고급 수준으로 교정을 받으려면 `~/.claude/settings.json`에 다음 내용을 추가합니다.

```json
{
  "env": {
    "CHINESE_PROOFREAD_LEVEL": "advanced"
  }
}
```

## 켜고 끄기의 세부 동작

- `/chinese-proofread:toggle`로 바꾼 상태는 `~/.claude/chinese-proofread/state.json`에 저장되므로, Claude Code를 다시 시작해도 유지됩니다.
- 이 명령은 사용자가 직접 입력할 때만 실행됩니다. Claude가 스스로 판단하여 기능을 끄거나 켜지는 않습니다.

### 특정 프로젝트에서 항상 끄기

중국어 문서를 다루는 저장소처럼 특정 프로젝트에서는 교정 기능을 항상 끄고 싶다면, 그 프로젝트의 `.claude/settings.json`에 다음 내용을 추가합니다.

```json
{
  "env": {
    "CHINESE_PROOFREAD_ENABLED": "0"
  }
}
```

- 이 환경 변수를 설정하면 `/chinese-proofread:toggle on`으로 켜 둔 상태와 관계없이 기능이 꺼집니다. `status`를 실행하면 환경 변수 때문에 꺼져 있다는 사실도 함께 알려 줍니다.
- 모든 프로젝트에서 항상 끄려면 같은 내용을 `~/.claude/settings.json`에 추가합니다. 다만 잠시 끄는 용도라면 환경 변수보다 `/chinese-proofread:toggle off`가 더 편리합니다.

## 교정 이력

고칠 부분이 있었던 교정 결과는 `~/.claude/chinese-proofread/history/` 폴더의 월별 파일(`2026-11.jsonl`)에 한 줄씩 쌓입니다. 달은 `time`과 같은 현지 시각을 기준으로 정합니다. 이 파일은 프로젝트와 세션을 구분하지 않으며, 저장소 안에는 생기지 않습니다.

```json
{"v": 1, "time": "2026-11-01T12:34:56+09:00", "lang": "Korean", "block": "📝 中文校对\n原文: 让他更快\n修正: 让它更快\n설명:\n- 사물을 가리킬 때는 它(tā)를 씁니다.\n---"}
```

| 필드 | 설명 |
|---|---|
| `v` | 기록 형식의 버전입니다. |
| `time` | 교정이 끝난 시각입니다. |
| `lang` | 교정 설명에 사용한 언어입니다. |
| `block` | 화면에 표시하는 교정 블록의 내용입니다. |

- `✅` 줄과 교정 실패는 기록하지 않습니다.
- 프롬프트 전체는 기록하지 않습니다. 다만 `原文` 줄에는 사용자가 쓴 문장이 그대로 들어갑니다.
- 파일은 자동으로 지워지지 않고 삭제하기 전까지 계속 남습니다. 오래된 기록을 지우려면 해당하는 달의 파일을 삭제하고, 기록을 모두 지우려면 `history` 폴더를 삭제합니다.
- 기록하지 못해도 교정 결과는 그대로 표시합니다.

### 교정 이력 요약하기

`/chinese-proofread:history [일수|all]`은 이력의 설명 줄을 읽어 다음 내용을 보여 줍니다. 인자를 생략하면 최근 7일을 읽습니다.

- 기간, 교정 횟수, 지적 건수: 설명 한 줄을 지적 한 건으로 셉니다.
- 유형별 건수: 다른 언어로 대체, 어휘 선택, 문장 구조, 문장부호, 오타로 나눕니다.
- 자주 틀린 패턴: 어휘 선택과 문장 구조에서 같은 원인으로 묶이는 패턴을 최대 세 개 보여 줍니다.
- 익혀 둘 표현: 영어나 한국어로 대신 쓴 단어의 중국어 표현을 최대 열 개 보여 줍니다.

요약에는 다음과 같은 제약이 있습니다.

- 요약은 현재 대화의 모델이 만들므로 토큰을 사용하고, 읽은 설명 줄이 대화에 남습니다. 최근 교정 기록을 최대 24,000바이트까지 읽으며, 보통 40~50회분에 해당합니다. 기간 안의 기록이 더 많으면 몇 회를 기준으로 삼았는지 알려 줍니다.
- 교정 횟수와 지적 건수는 스크립트가 세지만, 유형별 건수와 패턴은 모델이 분류하므로 실행할 때마다 조금씩 달라질 수 있습니다. 따라서 건수가 달라졌다고 해서 실력이 달라졌다고 볼 수는 없습니다.
- 이력은 개발 지시를 쓰면서 쌓이므로, 요약에는 개발 용어와 업무 표현이 많이 나타납니다.

## 교정을 실행하지 못할 때

- `python3`은 Python 3.9와 3.14에서 테스트합니다. `python3`이 없으면 교정이 동작하지 않고, 입력할 때와 답변이 끝날 때 `python3: not found` 훅 오류가 표시됩니다. 요청한 작업은 그대로 진행됩니다.
- 교정은 훅이 실행하는 `claude -p`로 진행합니다. 교정을 실행하지 못하면 작업은 그대로 진행하고, `⚠️ 中文校对: proofreading failed (...)` 줄로 실패 이유를 알려 줍니다.

## 그 밖의 한계

자주 겪을 수 있는 한계는 [README의 알아 둘 점](../README.md#알아-둘-점)에서 설명합니다. 이 절에서는 나머지 한계를 설명합니다.

### 판별과 교정

- 한글 없이 한자만으로 쓴 일본어 문장은 중국어로 판별될 수 있습니다.
- 직접 쓴 중국어인지 인용한 중국어인지는 교정 에이전트가 판단하며, 판단이 틀리면 인용한 중국어를 교정하거나 직접 쓴 단어를 놓칠 수 있습니다.
- 교정 설명의 내용은 평가로 검증하지 않았으므로, 틀린 설명이 나올 수 있습니다. 정규식 채점자는 형식만 확인합니다.

### 언어

- `CHINESE_PROOFREAD_LANG`을 한국어나 영어가 아닌 언어로 설정하면 설명에 한국어가 남을 수 있습니다. 교정 규칙이 한국어로 되어 있어 모델이 그 문장을 따라 쓰는 것으로 보입니다. `function`처럼 영어 단어를 섞은 문장에서 일본어는 10회 모두, 프랑스어는 6회 중 4회 한글이 남았습니다.
- 대화 응답의 언어는 Claude가 지시를 따르는 데 의존하며, 플러그인은 최종 답변이 대부분 중국어일 때만 한 번 다시 쓰게 합니다. 따라서 Claude가 중국어로 먼저 답한 내용은 화면에 남고, 다시 쓰는 동안 답변 1회분의 사용량이 더 듭니다. 작업 중의 진행 상황은 다시 쓰지 않습니다.
- `中文`이나 `汉语`를 쓰지 않고 중국어 문구를 써 달라고 요청하면(예: `帮我写一句生日祝福的话`), 답변이 지정한 언어로 다시 쓰입니다. 처음 쓴 중국어 문구는 화면에 남습니다.
