### 측정 방법

- 라벨은 "훅이 반응해야 하는가"를 뜻하며, 데이터셋의 `usage` 필드에서 두 기준으로 계산합니다.
  - **현재 기준**: 사용자가 직접 쓴 중국어 문장(`sentence`)만 true입니다.
  - **단어 포함 기준**: `sentence`와 함께, 한국어나 영어 문장에 사용자가 직접 섞어 쓴 중국어 단어(`word`)도 true입니다. `TODO.md`의 9-5를 진행할지 결정하는 데 씁니다.
- 지표는 재현율(true 문장 중에서 훅이 반응한 비율)과 오탐률(false 문장 중에서 훅이 잘못 반응한 비율)입니다. 정밀도는 데이터셋에 들어 있는 true 문장의 비율에 따라 값이 달라지므로 참고용으로만 적습니다.
- 설정값은 조정용 세트로만 골랐고, 확인용 세트는 설정값을 정한 뒤에 한 번만 실행했습니다.
- 설정값을 고르는 기준은 측정 도중에 한 번 바꾸었습니다. 바꾼 이유는 `docs/design-decisions.md`의 12번 항목에 기록했습니다.

  2. 바꾼 기준은 다음과 같습니다. 먼저 `zh_pure`, `zh_traditional`, `zh_with_code`, `zh_english_substitute` 범주를 모두 잡고, `ko_pure`, `en_or_code`, `zh_short_reply` 범주에는 하나도 반응하지 않는 설정만 남깁니다. 남은 설정 중에서 기본값보다 반응한 true 문장이 적지 않고 오탐도 많지 않으면서 둘 중 하나는 더 나은 설정이 있을 때만 기본값을 바꿉니다.

### 결과 해석

- 이 데이터셋의 오탐률은 실제 사용 환경의 오탐률보다 높습니다. 데이터셋에는 판별하기 어려운 false 문장을 일부러 많이 넣었기 때문입니다. 실제로 가장 많이 들어오는 한국어 요청과 영어 요청(`ko_pure`, `en_or_code`)에서는 전체 데이터셋에서 오탐이 하나도 없었습니다.
- 오탐은 대부분 영어 요청에 한자가 섞인 문장과, 한국어 요청에 중국어를 붙여 넣은 문장에서 발생합니다. 이런 입력에서 오탐이 생기면 지시문만큼 토큰이 소비되지만, 스킬은 사용자가 직접 쓴 중국어 문장이 없으면 언급하지 않고 교정을 건너뜁니다. 이 동작은 `TODO.md`의 9-1에서 확인했습니다.
- 단어 포함 기준에서는 한자 수와 비율만으로 직접 쓴 단어와 인용한 중국어를 구분할 수 없었습니다. 조정용 세트에서 단어 포함 기준의 재현율을 0.946까지 올리면 오탐률이 0.414가 되고, 오탐률을 0.034까지 낮추면 재현율이 0.589로 떨어집니다.
